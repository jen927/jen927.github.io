JS array

The new Array() constructor creates an Array object. Ways to do this are:

  1. Array()
  2. Array(number)
  3. Array(element1, element2, ..., elementN)

Number 1 creates an empty array. Number 2 creates an array with X number of empty spots. Number 3 creates an array with the list of elements given.

Some Methods

  • array.length: returns size of array
  • array[index]: returns element at index
  • array.push(element): adds a new element to the end of the list
  • array.pop(): removes last element of list and returns the element
