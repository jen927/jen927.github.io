JS Loops

When a variable is declared with let or const inside a loop, it will only be visible within the loop. for and while loops are similar to other programming languages.

for (let i = 0; i < 10; i++) { console.log(i); }

The above example will print 0 to 9 to console.

while (i < 5) { console.log(i); i++; }

The above example will print i to the console as long as i is less than 5.

do while

Similar to while loops, but it will execute the code block one time before checking the conditions are true.

do { something } while (condition)
