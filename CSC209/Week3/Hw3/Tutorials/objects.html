JS Objects

Objects are variables that can store both values and functions.

Values are stored as key:value pairs called properties. You access this two ways: Object.property OR Object[property].

Functions are stored as key:function() pairs called methods. The keyword this is used to access the object that is calling a method. The keyword makes it possible to use the same method with different objects.

To display an object's, we can use a for loop or an Array.
