Function Expression

A Function Expression are functions stored in a variable.

Examples

const varName = function(a, b) { return a + b; };

const varName = function add(a,b) { return a + b; };

In the first example, the function isn't named, so to invoke it, we would use varName(a,b). While, they can be named, we still invoke using varName.
