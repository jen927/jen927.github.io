JS Syntax

JS Keywords

JS keywords are used to create variables. There are two keywords used:

  • let
  • const

Keywords are case-senstive. Therefore, LET will NOT be interperated as let. You can define a variable using let and later assign it a value. However, this not true for const.

You use const if the variable's value will not change. It's good programming practice to define/declare all variables at the beginning of the script.

let and const provide block scope in JS. Meaning, if a variable is declared inside a { block }, then the variable cannot be accessed outside the block. All variables provide funciton scope as well.

JS Expressions

An expression is a combination of values, variables, and operators, which computes to a value.
