JS Operators

Operators are for Mathematical and Logical Computations.

List of Arithmetic operators:

  • +: Addition
  • -: Subtraction
  • *: Multiplication
  • /: Division
  • **: Exponentiation
  • %: Modulus
  • ++: Increment
  • --: Decrement

List of Assignment operators:

  • x = y: x = y
  • x += y: x = x + y
  • x -= y: x + x - y
  • x *= y: x = x * y
  • x /= y: x = x / y
  • x %= y: x = x % y

List of Comparison Operators:

  • x == y: true if x is equal to y
  • x === y: true if x is equal to y AND is the same type
  • x != y: true if x is not equal to y
  • x !== y: true if x is not equal to y OR not equal type
  • x > y: true if x is greater than y
  • x < y: true if x is less than y
  • x >= y: true if x is greater than or equal to y
  • x <= y: true if x is less than or equal to y

Logical Operators

  • a && b: logical and
  • a || b: logical or
  • !b: logical not

Logical Assignment Operators

a &&= b
b is assigned to a if and only if a is true.
a ||= b
b is assigned to a if and only if a is false.
a ??= b
b is assigned to a if and only if a is null/undefined.
