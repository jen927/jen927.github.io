Lists Tutorial

Ordered List

Starts with the "ol" tag to indicate its a ordered list, meaning the list is numbered by default.

Example of a default ordered list

  1. Coffee
  2. Juice
  3. Water

Unordered List

Starts with the "ul" tag to indicate it's a unordered list. By default, each item is marked by bullets.

Example of a default unordered list

  • Coffee
  • Juice
  • Water

Description List

Starts with the "dl" tag to indicate it's a description list. The tag "dt" denotes the item and the tag "dd" describes the item.

Example:

Coffee
- black hot drink
Milk
- white cold drink
